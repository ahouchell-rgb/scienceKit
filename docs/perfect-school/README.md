# The Perfect School — for a high-deprivation, high-SEND community

A top-down design exercise (July 2026): what would the ideal English school for a low socio-economic, high-deprivation, large-SEND catchment look like — structure, curriculum, governance — built from research evidence and the operators who have actually succeeded, and then, what has to be done to facilitate it.

Built by a multi-agent research programme (18 web-researched briefs → Opus-drafted blueprint → adversarial critique across coherence, evidence-fidelity and UK-2026 feasibility → revision → action plan).
